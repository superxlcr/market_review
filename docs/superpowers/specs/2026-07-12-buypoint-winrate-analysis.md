> 配套脚本:[`scripts/winrate_analysis.py`](../../../scripts/winrate_analysis.py)
> 工具设计:[2026-07-11-buypoint-winrate-design.md](./2026-07-11-buypoint-winrate-design.md)
> 系统口径:memory `trading-system-design-goal`(捕捉30%+趋势;实盘先筛标的+评估行情)

本文件是**累积式**的:方法论固定,底部「运行记录」每来一批新数据就追加一条对比。

## 1. 定性:这个工具在量什么

- **买点胜率工具 = 验证「最差情况地板」**。离场故意保持机械(固定止盈止损),**不把止盈、选股做进回测**——那两件太复杂,是实盘的人工环节。
- **指标 = 胜率**,定义为一笔交易的**峰值浮盈(`mfp_pct`)是否曾摸到判赢阈值(默认 +10%)**(数据里的 `success` 列)。
  它回答:"买了这个信号、机械持有,至少给过一次 +10% 浮盈机会的概率有多大?"
- **不看期望收益**:在 +20% 硬顶 / +10%武装-+5%回落 这套摆动离场下,四个买点期望都 ≈0,那是趋势跟随的正常特征(靠少数肥尾赚钱),不是要修的 bug。修的方向不是"砍赢家提前止盈"——那违背 30%+ 趋势的系统目标。
- **position-less（v9.2.0）**:引擎已改为**每个信号独立评估**(去掉"建仓后跳过持仓期"的持仓概念),胜率是纯粹的信号体检。持仓/冷却规则若要,在**分析层**事后对信号流做区间去重即可(CSV 有 signal/entry/exit_date)。
- **数据卫生**:引擎数据到底不再产出「回测结束」右删失单(源头 `return None`),分析层无需再清洗。

## 2. 方法论:五类切角,各回答一个问题

| # | 切角 | 回答的问题 | 主要陷阱 |
|---|------|-----------|---------|
| ① | **基线画像** | 这个买点一般长什么样(胜率/持有天/峰值浮盈/出场原因分布) | 出场原因里「收盘止损」占比高 ≠ 坏,那是趋势破位的正常离场 |
| ② | **手段胜率抬升** | 哪些条件(行业/市值/均线态)能抬高胜率,抬多少(pp=百分点) | 单维度切多了会**过拟合**;必须看样本数,小样本的极值不可信 |
| ③ | **样本外稳健性** | ②挖出的手段是真规律还是本段行情的巧合 | 前半段(H1)选条件、后半段(H2)应用;**in-sample 抬升一定会缩水**,看缩水后还剩多少 |
| ④ | **买点竞争** | 多个买点谁做主力;它们是抢同一批机会还是互补 | 用 **Jaccard 重叠**(同 code+同日)判断冗余/互补,不能只比胜率 |
| ⑤ | (止损调参) | 止损幅度/收盘止损/ATR 怎么调 | **不在本脚本范围**——改离场会改变胜率本身,必须重跑扫描,见下 |

### 为什么止损调参必须重跑扫描
胜率 = "峰值浮盈曾摸到 +10%"。**止损收得越紧,越多单在摸到 +10% 之前就被扫出局,峰值浮盈被截断、胜率反而下降**;收得越松,胜率升但尾部亏损变大。所以那一轮本质是跑一条 **「止损松紧 ↔ 胜率 vs 尾亏」权衡曲线**,需要用不同 `空间止损幅度% / 启用ATR止损 / 收盘止损` 配置各跑一遍全市场扫描,而非在单一 CSV 上事后切片。

## 3. 如何复跑与对比

```bash
# 1) 在「买点胜率」页跑一次全市场扫描 → 自动落盘到 .winrate_data/<时间戳>/
#    （每买点一个 CSV + config_snapshot.txt 记录本次生效配置）
# 2) 运行分析器（默认自动读最新 run）
.venv/Scripts/python scripts/winrate_analysis.py
.venv/Scripts/python scripts/winrate_analysis.py --data-dir .winrate_data/<时间戳>  # 指定历史 run 对比
```

对比新旧数据时重点看:**基线胜率排名是否变化**、**行业杠杆的样本外抬升是否还在**、**买点重叠结构是否稳定**。把新一轮结论追加到下面「运行记录」。

## 4. 运行记录(累积)

### 2026-07-12 — 首轮(数据跨度 20250102 ~ 20260709,29,885 笔)

> ⚠️ **本轮为旧「持仓模型」下的结果**（建仓后跳过持仓期；买点仅 4 个：扣抵量/5日均量均线支撑 + 回调一半 + 波段50%）。v9.2.0 改为 **position-less + 11 买点**后**结论需重扫复核**;本轮原始 CSV 已删,以下为文字留档。方向性结论(回调一半=主力、行业是唯一稳健杠杆)预计不变,具体数字会变。

配置:`开始日期=20250101 / 长期均线排列=多头|盘整 / 市值下限=150亿 / 时间止损=13 / 大胜利止盈=20 / 空间止损=5%`。

**① 基线画像**

| 买点 | 笔数 | 基线胜率 | 平均持有 | 平均峰值浮盈 |
|---|---|---|---|---|
| 回调一半 | 4142 | **25.8%** | 2.2天 | 6.5% |
| 波段50% | 4615 | 22.4% | 2.6天 | 5.8% |
| 5日均量均线支撑 | 10595 | 17.7% | 3.8天 | 5.3% |
| 扣抵量均线支撑 | 10533 | 17.4% | 3.9天 | 5.3% |

**② 手段** — 真正的大杠杆**只有行业**;市值(躲大盘 −3pp)、长均态(多头 +2pp)次要;**短均态是噪声**(多头/空头/盘整 ±0.5pp),不值得当过滤。
行业细节(均线支撑):电子 +9.9pp、通信 +5.7、电力设备 +4.1、计算机 +3.9;银行 **−14.1**、食品饮料 −9.1、交运 −8.4、非银 −7.4。
⚠️ 坑:本轮配置 `长期均线排列=多头|盘整` 已**过滤掉长均空头**,所以"长均多头 +2.4pp"只是"多头 vs 盘整"对比,**长均空头的影响本批数据未测**,要放开配置专门重跑才知道。

**③ 样本外稳健性** — 行业杠杆**站得住**:H1(202501~11)选出的好行业,拿到 H2(202512~) 应用,胜率 **24.0% vs 基线 21.9%(样本外 +2.1pp)**,H1差行业在 H2 仅 17.3%。行业胜率 **H1 vs H2 秩相关 0.67**——头尾很稳(电子恒强、银行/交运/非银恒弱),中间会轮动(煤炭/公用/建筑在 H2 翻红)。
→ 正确用法:**切入启动了的领涨板块 + 硬躲防御板块(银行/交运/非银)**,不是焊死榜单。in-sample ~5pp 里约 +2pp 是真实可用的,其余是过拟合。

**④ 买点竞争** — 关键发现:**它们基本不重叠**。

| | 扣抵量均线支撑 | 5日均量 | 回调一半 | 波段50% |
|---|---|---|---|---|
| 扣抵量均线支撑 | — | **77.7%** | 1.3% | 2.9% |
| 回调一半 | | | — | 1.0% |

- 两个均线支撑变体 **77.7% 重叠、胜率一致 → 冗余,砍一个**(留扣抵量,删5日均量)。
- 其余三个两两只 1~3% 重叠 → **互补,不是二选一**,是"以谁为主力"。
- 套动量行业过滤:回调一半 26.6%(+0.8)、波段50% 23.2%(+0.8)、均线支撑 22.3%(**+4.9**)。回调一半几乎不吃行业过滤就已最高,说明**它的回调结构自带选股、不依赖猜板块**。

**结论**
1. **主力买点 = 回调一半**(突破回踩):地板最高、样本外最稳、不靠猜板块。与实盘体感一致。
2. **均线支撑**:旧模型下今日量≈5日均量(77.7%重叠、胜率一致);定位"高频补充",且必须绑定动量行业白名单,否则全场最差。→ v9.2.0 **不急着砍**,改为**拆开验证**:量确认(今日量/5日均量/无量)× 周期(MA20/55/60/120/144/240),下轮 position-less 数据出来再定主力。
3. 波段50% 作与回调一半同族的互补次要信号。
4. 下一步进「止损调参」轮:多档 `空间止损 / 收盘止损开关 / ATR` 重跑扫描,画权衡曲线。
