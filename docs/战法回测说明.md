# 战法回测说明

> AI v1.28.3 | 2026-06-27

## 策略总览

### 单战法（7 个类）

| 策略 | 类名 | 类型 | 说明 |
|------|------|------|------|
| MA55 突破拉回 | `ma55_breakthrough` | 均线 | 突破/拉回 MA55 |
| MA60 突破拉回 | `ma60_breakthrough` | 均线 | 突破/拉回 MA60 |
| MA120 突破拉回 | `ma120_breakthrough` | 均线 | 突破/拉回 MA120 |
| MA144 突破拉回 | `ma144_breakthrough` | 均线 | 突破/拉回 MA144 |
| 突破回调一半 | `half_retrace` | 价格形态 | 找历史前低 V → 计算半分位入场 |
| 突破回调一半(简化) | `half_retrace_simple` | 价格形态 | V = P / 2.33（固定比，不查历史） |

### 组合战法（3 个，基于 CompositeStrategy）

| 策略 | 类名 | 子战法（按优先级） |
|------|------|------|
| 回调一半 + MA55 | `half_retrace_ma55` | `half_retrace` → `ma55_breakthrough` |
| MA60 + MA120 | `ma60_ma120` | `ma60_breakthrough` → `ma120_breakthrough` |
| MA55 + MA144 | `ma55_ma144` | `ma55_breakthrough` → `ma144_breakthrough` |

> **核心原则：以什么为买点进，就以什么为买点止盈止损。** 买入时记录 `strategy_tag`，卖出时路由到对应子战法。

## 买入信号

### 均线系列（MA55 / MA60 / MA120 / MA144）

| 信号 | 条件 | 买入价 |
|------|------|--------|
| 突破MA | 昨日收盘 < 昨日MA **且** 今日最高价 ≥ 今日MA | 当日MA |
| 拉回MA | 昨日收盘 > 昨日MA **且** 今日最低价 ≤ 今日MA | 当日MA |

### 突破回调一半 (`half_retrace`)

1. 在历史 K 线中找前低 V（前一个局部最低价）
2. 验证 V / P < 3/7（确保中点 < 62.5% 线）
3. 62.5% 线 = V + 0.625 × (P − V)
4. 必须曾跌破 62.5% 线
5. 半分位 = (P + 跌破62.5%后的最低价) / 2
6. 当日最高价 ≥ 半分位 → 买入

### 突破回调一半(简化) (`half_retrace_simple`)

1. 找 P（阶段性最高收盘价），前 5 日居中唯一高点
2. **V = P / 2.33**（固定比例，不查历史）
3. 62.5% 线 = V + 0.625 × (P − V)
4. 必须曾跌破 62.5% 线
5. 半分位 = (P + 跌破62.5%后的最低价) / 2
6. 当日最高价 ≥ 半分位 → 买入

### 组合战法 (`composite.py`)

遍历子战法列表，**第一个**返回 BuySignal 的生效，记录 `strategy_tag`。所有子战法无信号则本轮不买。

## 卖点优先级

### 均线系列

| 优先级 | 类型 | 条件 | 卖出价 |
|--------|------|------|--------|
| — | **空间止损**（引擎层） | 最低价 ≤ 买入价 × (1 − 止损%) | 开盘/盘中价 |
| 1 | **战法卖出** | 收盘价 < 当日进场MA | 收盘价 |
| 2 | **时间止损** | 持仓≥8交易日 且 最大浮盈从未达10% | 收盘价 |
| 3 | **三级止盈** | 见下方 | 见下方 |

### 价格形态系列（half_retrace / half_retrace_simple）

| 优先级 | 类型 | 条件 | 卖出价 |
|--------|------|------|--------|
| — | **空间止损**（引擎层） | 同均线系列 | 开盘/盘中价 |
| 1 | **战法卖出** | 收盘价 < 突破价（买入价） | 收盘价 |
| 2 | **时间止损** | 持仓≥8交易日 且 最大浮盈从未达10% | 收盘价 |
| 3 | **三级止盈** | 见下方 | 见下方 |

> 均线系列的"战法卖出"以 `entry_ma_type` 对应的均线为准（`strategy_tag` 绑定）。价格形态系列以突破价为参考。

## 三级浮盈止盈

| 级别 | 曾达浮盈 | 触发条件 | 卖出价 |
|------|---------|---------|--------|
| Tier 1 | < 10% | 不止盈 | — |
| Tier 2 | 10% ~ 20% | 日内最低价 ≤ 买入价 × 1.05 | 买入价 × 1.05（锁5%） |
| Tier 3 | ≥ 20% | 日内最低价 ≤ 买入价 × (1 + 最高浮盈% × 50%) | 保50%价位 |

**示例：**
- 买入价 100，最高涨到 115（浮盈 15%）→ Tier 2 → 跌到 104 → 卖出 @105（锁 5%）
- 买入价 100，最高涨到 130（浮盈 30%）→ Tier 3，保 15% → 阈值 115 → 卖出 @115

加仓部分也有独立的三级止盈，阈值相同但使用加仓成本价计算。

## 浮盈加仓 🆕

基础仓位最大浮盈达到阈值后，追加**一半仓位**。每笔持仓限一次。

| 特性 | 说明 |
|------|------|
| 触发条件 | 基础仓位 MFP ≥ 加仓阈值%（配置第 7 字段） |
| 加仓股数 | `base_shares // 2`（股数一半） |
| 加仓价 | 跳空高开→开盘价；盘中触发→条件单价 `buy_price × (1 + threshold%)` |
| 次数限制 | **1 次**（`addon_count` 不可逆计数器） |
| 开仓上限 | **不算入**开仓上限 |
| 独立止盈 | 三级止盈 + 空间止损，用加仓自身成本价计算 |
| 跟随卖出 | 基础仓位卖出时，加仓同步卖出（"跟随卖出"） |

配置：第 7 字段写 `999` = 不启用加仓。写 `10` = MFP≥10% 时触发。

## 组合战法模式

`CompositeStrategy` 基类：

```python
class HalfRetraceMA55Strategy(CompositeStrategy):
    SUB_STRATEGIES = ["half_retrace", "ma55_breakthrough"]
```

- **买入**：按 `SUB_STRATEGIES` 顺序检查，先命中先生效。`strategy_tag` 记录命中子战法名。
- **卖出**：通过 `pos.strategy_tag` 路由到对应子战法的 `check_sell()`。
- **好处**：一个配置覆盖多种入场逻辑，优先买最好的形态；卖出也用同一套逻辑。

```ini
MA55+MA144_时间止损      ma55_ma144          20 2 5 10 999
```

| 字段 | 说明 | 默认 |
|------|------|------|
| 策略名 | 页面下拉显示名 | — |
| 战法类名 | `@register_strategy("xxx")` | — |
| 仓位% | 单笔交易占总资金比例 | 20 |
| 开仓上限 | 基础最大同时持仓数 | 2 |
| 空间止损% | 跌破买入价 X% 即止损 | 5 |
| 开仓浮盈阈值% | 持仓浮盈曾达此值 → +1 开仓上限 | 10 |
| 加仓阈值% | 基础 MFP 达此值触发加仓；`999` = 不启用 | 999 |

## 引擎层风控

| 机制 | 说明 |
|------|------|
| **空间止损** | 配置项 `空间止损%`，最低价触及买入价×(1−X%) 即止损（引擎层，所有策略通用） |
| **开仓上限** | 基础最大持仓数 + 浮盈达标解锁数 |
| **加仓逻辑** | 浮盈达标 → 半仓追加，不限开仓数，仅一次 |
| **T+1** | 当日买入，次日才能卖出 |
| **回测清仓** | 回测最后一天以收盘价强制清仓 |
| **市值估值** | 每日净值按持仓收盘市价（mark-to-market）计算 |
| **同轮同序** 🆕 | 同轮所有策略共享 random seed，消除买入顺序噪音 |
| **多轮取均值** | Dashboard 支持 N 轮回测取均值，净值曲线显示 min~max 区间带 |

## Dashboard 显示

| 指标 | 说明 |
|------|------|
| 净值曲线 | 多策略叠加，多轮显示均值线 + min~max 区间 |
| 策略对比汇总表 | 交易笔数、胜率、总收益、最大回撤、平均持仓、盈亏比 |
| 交易明细 | 每笔买卖的日期/价格/盈亏/原因/当前持仓快照 |
| 股票明细 | 每只票的胜率、**金额加权累计收益**、**对总净值贡献(+x.xx%)** |
| 红绿配色 | 🟢 累计收益 ≥ 0、🔴 累计收益 < 0 |

> 累计收益已改为**金额加权**（非简单累加百分比）：基础仓位和加仓仓位按各自成本加权。
> 括号内 `(+x.xx%)` = 该股票对 100 万总本金的净利润贡献。

## 添加新战法

1. 在 `src/marketreview/backtest/strategies/` 新建 `.py`
2. 继承 `BaseStrategy`，实现 `check_buy()` 和 `check_sell()`
3. 用 `@register_strategy("类名")` 装饰
4. 在 `strategies/__init__.py` 中 import
5. 在 `engine.py` 的 `__init__` 方法中添加 import（确保注册）
6. 在 `config/backtest_strategies.txt` 添加配置（7 字段）
7. 更新本文档

### 组合战法

无需新建文件，在 `composite.py` 中添加子类：

```python
@register_strategy("my_combo")
class MyComboStrategy(CompositeStrategy):
    SUB_STRATEGIES = ["half_retrace", "ma55_breakthrough"]
```

子战法名对应 `@register_strategy("xxx")` 中的注册名。
