# 战法回测说明

> AI v1.12.17 | 2026-06-27

## 已注册战法

### 1. MA60 突破+拉回 (`ma60_breakthrough`)

**买点（任一触发）：**

| 信号 | 条件 | 买入价 |
|------|------|--------|
| 突破MA60 | 昨日收盘 < 昨日MA60 **且** 今日最高价 ≥ 今日MA60 | 当日MA60 |
| 拉回MA60 | 昨日收盘 > 昨日MA60 **且** 今日最低价 ≤ 今日MA60 | 当日MA60 |

**卖点（按优先级）：**

| 优先级 | 类型 | 条件 | 卖出价 |
|--------|------|------|--------|
| 1 | MA60止损 | 最低价 ≤ 昨日MA60 × 0.97 | 开盘价 < 止损价 → 开盘价；否则止损价 |
| 2 | 空间止损 | 最低价 ≤ 买入价 × (1 − 止损%) | 开盘价 < 止损价 → 开盘价；否则止损价 |
| 3 | 战法卖出 | 收盘价 < 当日MA60 | 收盘价 |
| 4 | 三级止盈 | 见下方 | 见下方 |

### 2. MA60 突破+拉回 无MA60止损 (`ma60_breakthrough_basic`)

买入同 #1。卖出去掉 MA60 3% 空间止损（仍保留引擎层空间止损）：

| 优先级 | 类型 | 条件 | 卖出价 |
|--------|------|------|--------|
| 1 | 空间止损 | 最低价 ≤ 买入价 × (1 − 止损%) | 开盘价 < 止损价 → 开盘价；否则止损价 |
| 2 | 战法卖出 | 收盘价 < 当日MA60 | 收盘价 |
| 3 | 三级止盈 | 见下方 | 见下方 |

### 3. MA60 突破+拉回 + 时间止损 (`ma60_breakthrough_time_stop`)

买入同 #1。卖出在 #1 基础上新增**时间止损**：

| 优先级 | 类型 | 条件 | 卖出价 |
|--------|------|------|--------|
| 1 | MA60止损 | 最低价 ≤ 昨日MA60 × 0.97 | 开盘/盘中价 |
| 2 | 空间止损 | 最低价 ≤ 买入价 × (1 − 止损%) | 开盘/盘中价 |
| 3 | 战法卖出 | 收盘价 < 当日MA60 | 收盘价 |
| 4 | **🆕 时间止损** | 持仓≥8交易日 且 最大浮盈从未达10% | 收盘价 |
| 5 | 三级止盈 | 见下方 | 见下方 |

> **时间止损：** 买入日不计，从次日开始算交易日。满 8 个交易日时若最大浮盈从未达到 10%，则在当日收盘卖出。例：1号买入 → 2,3,4,5,8,9,10,11（跳过周末6,7）→ 11号收盘时浮盈未达10% → 收盘卖出。

### 4. MA60 突破+拉回 + 时间止损 无MA60止损 (`ma60_breakthrough_basic_time_stop`)

买入同 #1。卖出 = #2 + #3 合并（无MA60止损 + 时间止损）：

| 优先级 | 类型 | 条件 | 卖出价 |

| 3 | 🆕 时间止损 | 持仓≥8交易日 且 最大浮盈从未达10% | 收盘价 |
| 4 | 三级止盈 | 见下方 | 见下方 |

## 三级浮盈止盈

开仓后追踪**日内最高价**的浮盈（`max_float_profit_pct`），根据曾达到的最高浮盈级别触发。逻辑在 `BaseStrategy.check_take_profit()` 统一实现，所有策略共享；子类可覆写类属性定制阈值。

| 级别 | 曾达浮盈 | 触发条件 | 卖出价 |
|------|---------|---------|--------|
| Tier 1 | < 10% | 不止盈，纯靠止损 | — |
| Tier 2 | 10% ~ 20% | 日内最低价 ≤ 买入价 × 1.05 | 买入价 × 1.05（锁5%） |
| Tier 3 | ≥ 20% | 日内最低价 ≤ 买入价 × (1 + 最高浮盈% × 50%) | 保50%价位 |

**可覆写类属性：**

| 属性 | 默认值 | 含义 |
|------|--------|------|
| `TP_TIER3_MFP_THRESHOLD` | `20.0` | 浮盈达此%触发 Tier 3 |
| `TP_TIER3_PROTECT_PCT` | `0.50` | Tier 3 保留最高浮盈的 50% |
| `TP_TIER2_MFP_THRESHOLD` | `10.0` | 浮盈达此%触发 Tier 2 |
| `TP_TIER2_PROTECT_PRICE_RATIO` | `1.05` | Tier 2 保护买入价的 +5% |

**示例：**
- 买入价 100，最高涨到 115（浮盈 15%）→ Tier 2 激活 → 某日最低跌到 104 → 触发止盈，卖在 105（锁 5%）
- 买入价 100，最高涨到 130（浮盈 30%）→ Tier 3 激活 → 保 50% = 15% → 阈值 115 → 某日最低跌到 114 → 触发止盈，卖在 115

## 引擎层风控

| 机制 | 说明 |
|------|------|
| **T+1** | 当日买入，次日才能卖出 |
| **空间止损** | 配置项 `空间止损%`，最低价触及买入价×(1−X%) 即止损 |
| **开仓上限** | 配置项 `开仓上限`，基础最大持仓数 |
| **浮盈解锁** | 配置项 `开仓浮盈阈值%`，每只持仓浮盈达标即 +1 仓位上限 |
| **回测清仓** | 回测最后一天以收盘价强制清掉所有持仓 |

## 配置文件

### 股票池 `config/backtest_pools.txt`

```ini
# 格式: [池名]
#       股票名 entry_date exit_date
# entry_date: 此日起可买入（YYYYMMDD）
# exit_date: 此日后不可买入，now = 最新交易日

[白大与nga池]
豪威集团 20260201 now
药明康德 20260301 20260430
```

### 策略 `config/backtest_strategies.txt`

```ini
# 格式: 策略名 战法类名 仓位% 开仓上限 空间止损% [开仓浮盈阈值%]

MA60_突破拉回_5止损_2个_2成              ma60_breakthrough              20 2 5 10
MA60_突破拉回_5止损_1个_3成              ma60_breakthrough              30 1 5 10
MA60_突破拉回_无MA60止损_2个_2成         ma60_breakthrough_basic        20 2 5 10
MA60_突破拉回_时间止损_2个_2成           ma60_breakthrough_time_stop    20 2 5 10
MA60_突破拉回_无MA60止损+时间止损_2个_2成 ma60_breakthrough_basic_time_stop 20 2 5 10
```

| 字段 | 说明 |
|------|------|
| 策略名 | 页面下拉显示名 |
| 战法类名 | 注册名，对应代码 `@register_strategy("xxx")` |
| 仓位% | 单笔交易占总资金比例 |
| 开仓上限 | 基础最大同时持仓数 |
| 空间止损% | 跌破买入价 X% 即止损 |
| 开仓浮盈阈值% | 持仓浮盈曾达此值 → 解锁 +1 仓位上限（可选，默认 0） |

## 添加新战法

1. 在 `src/marketreview/backtest/strategies/` 新建 `.py`
2. 继承 `BaseStrategy`，实现 `check_buy()` 和 `check_sell()`
3. 用 `@register_strategy("类名")` 装饰
4. 在 `strategies/__init__.py` 中 import
5. 在 `config/backtest_strategies.txt` 添加一行配置
6. 更新本文档
