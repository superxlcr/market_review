# 复盘流程 (Review Process)

## 触发方式

新 session 说 **「复盘」** 或 **「复盘 YYYY-MM-DD」** 即可进入复盘流程。

> **💡 Session 标题**：CC 会话标题自动取自第一条消息。复盘时建议第一条消息直接写 `YYYYMMDD A股复盘`（如 `20260803 A股复盘`），方便在侧边栏辨识。

## 前置条件

1. **AI 负责启动 Dashboard** — 复盘触发时，AI 自动 kill 旧进程 + 启动 Streamlit（参考 [[dashboard-setup]]），用户只需在页面点击"加载数据"
2. Dashboard 加载数据 → 自动生成 `journal/data-YYYY-MM-DD.md`
3. 上次复盘结论在 `journal/review-YYYY-MM-DD.md`（首次跳过 Step 0）

## 完整流程文档

详见 `journal/REVIEW_FLOW.md`

## 四个步骤

| Step | 内容 | 原则 |
|------|------|------|
| 0 | 加载上次结论，check 待观察信号 | 先回顾再分析 |
| 1 | 盘点今日盘面（数据 + 用户补充分时/外部） | 一次一个问题，不等回答完不推进 |
| 2 | 大方向判断（波浪位置、信号、边界） | 模糊的方向框架，不追求精确预测 |
| 3 | 持仓与操作（左侧/右侧、入场/止损） | 落实到具体操作 |

## Step 1 固定问题

1. **现在大盘处于什么阶段？**（波浪位置/趋势状态/关键支撑压力）
2. **昨天外部发生了什么？**（美股/宏观/政策事件）→ 怎么传导到今天的盘面？—— **AI 主动搜索新闻，不等用户补充**
3. **今天分时节奏怎么样？**（高开/低开？日内转折点？尾盘异动？国家队痕迹？）
4. **今天不同板块/风格的节奏差异？**（谁先动、谁后动、谁跟谁、谁独立？有没有合力？）

## Step 2 固定问题

1. **当前浪型的确认信号是什么？**（站上什么位置？多久？）
2. **反弹/下跌的空间和边界？**（目标位、压力位、支撑位）
3. **什么板块/方向可能有机会？**（结合定调，选股还是宽基？）
4. **什么情况下这个框架失效？**（跌破哪里重画？突破哪里升级？）

## Step 3 固定问题

1. **当前持仓状态？**（左侧多少、右侧多少、有没有被套的）
2. **具体操作计划？**（入场/退出/止损条件）
