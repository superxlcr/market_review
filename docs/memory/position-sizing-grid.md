# 仓位网格框架

## 核心参数

| 参数 | 值 | 原因 |
|------|-----|------|
| 单标上限 | **20%** | 个股/ETF统一 |
| 底仓 | **10%** | 建仓时一次打出 |
| 网格份数 | **5份 × 2%** | 弹性最大 |
| 网格间距 | **每跌 5%** 补一份 | -20%止损前能填4份 |
| 止损 | **-20%（结构位优先）** | 总资金亏 ≤3% |

## 触发线（D=5%）

```
10% @ P        <- 底仓
+2% @ -5.0%    <- 补#1
+2% @ -9.8%    <- 补#2
+2% @ -14.3%   <- 补#3
+2% @ -18.5%   <- 补#4（-20%止损前最后一份）
+2% @ -22.6%   <- 止损后，买不到
────────────────
20% 合计
```

## 止损时亏损

| 止损线 | 填满 | 持仓 | 均价 | 总资金亏 |
|--------|------|------|------|----------|
| -20% | 4/5份 | 18% | 0.947P | **2.80%** |

## 实践规则

- 10%底仓一次性建，剩下的等回调补
- 到达结构止损位（A底/MA60/前低），不管网格填到哪，一刀砍
- 剩 2% → 趋势确认回水上时一把打入，或留着不补
- 网格作用是"跌了有纪律地接"，不是"一定要接满"。接不满说明跌不够深，是好事

## 两种模式

| 模式 | 条件 | 建仓方式 |
|------|------|----------|
| A 水下/左侧 | 价格在MA60下方 | 10%底仓 + 5%间距网格补4份 = 18% |
| B 水上/突破 | 站上MA5×3天+放量+板块共振 | 10%底仓 + 10%一次性 = 20% |

两种到达同一终点（~20%），A赚耐心B赚确定性。
