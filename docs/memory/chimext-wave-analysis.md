## 结构原理

- **3浪延长(1.618×1浪) → 5浪=A浪(1:1)**：3浪消耗了主升能量，5浪只是惯性冲高（冲动资金），A杀精准清算5浪，吃不掉3浪的基本面成果
- **4浪极浅(17%)**：3浪+94.5%积累巨大动能，筹码惜售，跌不动
- **2浪半年横盘**：1浪太短太猛（40天+70%）→ 顶部套牢盘密集 → 需要长时间消化
