# 族群效应分析 — 回调一半买点胜率

**日期**: 2026-07-15 分析
**数据**: `.winrate_data/20260715_140945/回调一半严格.csv`
**分析脚本**: `scripts/analyze_breakout_sequence.py`, `scripts/analyze_direction.py`, `scripts/analyze_rewatch.py`

## 核心发现

### 1. 族群效应确实存在

| 阈值 | 族群 WR | 孤狼 WR | 差值 | 过滤噪声 |
|------|---------|---------|------|----------|
| ±1天, ≥2同行 | ~35% | ~27% | +8pp | 过滤太多 |
| **±2天, ≥3同行** | **~31%** | **~27%** | **+4pp** | **过滤~48%** |
| ±3天, ≥3同行 | ~30% | ~27% | +3pp | 效果减弱 |

**最佳窗口: ±2 交易日, ≥3 个同行** — 在不过度过滤和 WR 提升之间平衡最好。

> ⚠️ **以上阈值是初步的**，基于申万分类跑出来的数字。概念标签（I型/N型）接入后，族群定义会更贴近真实资金流向，窗口大小、同行数量阈值都可能需要重新校准。这些数字是方向性结论，不是固定参数。

### 2. 申万 L1 分类与资金视角不一致

- 赣锋锂业（有色金属）和天赐材料（电力设备）同属锂电产业链，但被分在不同 L1
- 电子/电力设备/机械设备经常同时出信号（Jaccard 相似度高），说明资金把它们当一个板块炒
- **结论**: L1 不适合做族群聚类的分类标准，需要更贴近资金逻辑的标签

### 3. 大盘群可能是假突破

- 20260227 有色金属 19票 WR=5%：铜/铝 M顶形态，熊市反弹中的假突破
- 集群是真实的（资金确实在炒有色），但方向错了
- **教训**: 族群密度能告诉你"资金在哪"，但不能告诉你"方向对不对"。需要叠加市场环境判断

### 4. L2 级别集群更精准

- 20260616 半导体 10票 WR=100%：纯半导体行情，L2 级别正确识别了资金集团
- 电子 L1 内部 L2 子行业差异大（半导体 vs 元器件 vs 光学光电子），混在一起会稀释信号

## 策略逻辑（核心思路）

**看整个市场的钱，涌向了什么位置，如果他们把股价拉过了一定程度，我们就介入。**

拆开来看三步：

1. **识别资金流向** — 通过族群密度（同概念多票同时触发信号）判断钱在往哪个板块涌。不是看单票，是看集群。独狼信号大概率是噪声。
2. **等待价格确认** — 资金涌进去只是第一步，要等价格真的拉过了关键位置（回调一半突破 = 解放套牢盘），才证明不是一日游。
3. **介入** — 确认后进场，吃趋势行情。

这里有两个可以调的"位置"参数：
- **族群窗口**（当前 ±2 天, ≥3 同行，概念标签后重新校准）
- **价格突破阈值**（回调一半 = 突破(P+L)/2 是当前买点；未来可能发现某些族群放量就开始进场，那个位置比回调一半更早）

逻辑上没问题。具体阈值等概念数据跑出来再调。

## 解决方案

### 新增同花顺概念标签

在 `tushare` 中增加了两个概念数据源：
- **`ths_index`** → `concept_index` 表：概念指数列表（I型=行业, N型=概念）
- **`ths_member`** → `concept_member` 表：每个概念的成分股

TradeResult 新增三个字段（替代已移除的 wave33/kd80 方向字段）：
- `industry_l3` — 申万三级行业
- `concept_i` — 同花顺 I 型行业分类（如"数字芯片设计"）
- `concept_n` — 同花顺 N 型概念标签（如"锂电池概念,PCB概念"，逗号分隔）
