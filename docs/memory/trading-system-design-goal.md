交易系统的设计目标是**捕捉 30%+ 盈利的趋势行情**(趋势跟随打法),不是做 +3/+5/+8 的小止盈。因此"提前止盈砍赢家"这个方向**违背系统设计,不予采纳**。

实盘操作有两道人工闸(数据分析必须对齐这两道):
1. **标的筛选** —— 只挑符合条件的标的参与。
2. **整体行情评估(regime)** —— 行情评估不行就**根本不下场**。

**Why:** 这决定了「买点胜率」数据的分析口径:低胜率 + 回吐是趋势跟随的**正常特征**(靠少数肥尾赚钱),不应通过"砍赢家提前止盈"来"修复"。而无差别吃下所有月份/所有信号的回测,会**高估亏损**,因为现实里差行情不参与。

**How to apply:** 分析买点胜率时——(a) 关注**肥尾捕捉**(20%+/30%+ 的分布与总收益贡献),而非平均止盈;(b) 叠加**行情 regime 闸门**重新评分,对齐"行情不行不参与"(见 [[market-panorama-reference]] 的大盘口径);(c) 注意现有回测把 `大胜利止盈%=20` 硬顶在 +20%,**低于 30% 目标、会砍短趋势肥尾**——用它前先确认它是"真实趋势系统的代理"还是"独立短线体检"。相关设计见 [[fundamental-analysis-design]]。
