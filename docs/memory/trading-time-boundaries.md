## 核心原则
**复盘要像上班一样，有下班时间。** 股市有时也讲究巧劲，埋头蛮干不一定有用。

## 三个边界

| 边界 | 含义 | 具体做法 |
|------|------|----------|
| 时间边界 | 每日交易相关有时间上限 | 盘后 30 分钟，到点关电脑打游戏 |
| 投入边界 | 不追求所有机会 | 只做最有把握的一两种简单信号 |
| 预期边界 | 不指望靠市场改变生活 | "大不了不赚了，我也不缺这个钱" |

## 因果链：投入过多 → 心态崩盘
```
投入大量时间精力 → 自然产生高期待 → 市场不按期待走 → 心态失衡 → 冲动操作 → 亏钱
```
解法：**在源头掐断。** 不让投入过度，就不会产生过高期待。

## 匹配用户习惯
- [[trader-profile]] 背单词模式：每天 10 新词 + 50 复习（可承受） vs 20 新词 + 100 复习（崩）
- 交易同理：盘后 10 分钟看两个候选、设条件单（可承受） vs 盘中盯盘追涨杀跌（崩）
- 交易系统应该像背单词：**轻量、可重复、不占用大块时间、靠长期积累而非短期爆发**

## 用户金句 (2026-07-12)
- "我应该就跟我工作一个态度：这个钱这么难赚，我大不了不赚了呗，赚点风险低的简单的嘛"
- "没有投入太多，自然不会过分期待，也能合理避免心态失衡"
- "有时候真的是做的越多错的越多"
- "工作只是生活的一部分，最后还得劳逸平衡，学会放弃一些不适合你性格赚的钱，过好生活最重要"
- "你走的如履薄冰，有时候反而能走得更远"

## 阶段论：新人努力 → 找准节奏
- 新人阶段可以多花时间学习——有很多东西要了解，努力一点是正常的
- 但最终一定要过渡到"找准自己的节奏"——不能永远用新人的投入强度
- 用户已确认自己的节奏：**慢慢来**
- 参考《通向财务自由之路》：交易系统第一步是设立目标，知道自己想赚多少钱
- 用户当前阶段目标：**学习为主，能不亏本就不错了**（而非追求高收益）

## 与交易系统设计的关系
设计任何交易功能时，必须考虑：
1. 每日操作时间是否 ≤ 30 分钟？
2. 是否需要盘中盯盘？（是 = 不合格）
3. 操作频率是否匹配用户的"懒但自律"特点？

**Why:** 用户已验证：投入过多 → 期待过高 → 心态失衡 → 亏钱。这是未来所有系统设计的约束条件。
**How to apply:** 设计新功能、讨论新策略时，先检查是否违反三个边界；违反则必须简化。
