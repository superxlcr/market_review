# 交易教训汇总

## 1. 趋势切换时最大的敌人是自己（2026-08-05）

**场景**：4-3/A杀 切换到 4-4/B反，但思维还停在下跌趋势中。

**表现**：
- 等个股/指数再踩一次甚至破前低 → 结果低点已过
- 丢了科创50底仓（怕反弹是假的）
- 光模块低开后等更低 → 日内修复完毕，踏空
- 整个4-4磨底的10天都在观望，没建仓

**根因**：用上一个阶段的框架做下一个阶段的操作。

**Why**: 下跌趋势中"等更低"是对的，因为卖压持续、利空被放大。反弹趋势中资金在"找理由买"，利空集中竞价一步到位、日内修复。同一个消息，同一个股票，4-3里能跌15%，4-4里只砸个开盘。

**How to apply**:
- 当关键支撑（3741）多次不破 + 利空低开即修复 → 趋势可能已切换，不要再等"理想的低点"
- 趋势切换后，操作方向从"反弹就减仓"转为"回踩就加仓"
- 每次复盘时主动问自己：现在是什么阶段？我的操作逻辑和这个阶段匹配吗？

## 2. 底仓不能丢（2026-08-05）

**场景**：0804 卖出科创ETF底仓，0805 科创暴涨4.78%。

**Why**: 在复杂磨底（4-4/B反）中，你不知道哪一天启动。磨了10天不动，第11天突然放量拉5%——等你反应过来已经晚了。底仓的作用不是赚这一波，是保证你一直在车上。

**How to apply**:
- B反/4-4 初期的磨底阶段，底仓（至少10-15%）不能动
- 可以T（日内高抛低吸），但收盘必须接回来
- 止损设在硬逻辑位（如A底1550），不是设在"感觉还要跌"

## 3. 利空在不同趋势中的表现完全不同（2026-08-05）

**场景**：光模块禁令 → 中际旭创低开14% → 预期带崩创业板 → 实际日内修复。

**Why**: 
- 下跌趋势：资金在"找理由卖" → 利空被放大 → 持续2-3天消化
- 反弹趋势：资金在"找理由买" → 利空竞价一步到位 → 10分钟消化完毕

**How to apply**:
- 反弹趋势中，利空低开就是上车点，不要等
- 判断标准不是利空本身的大小，是当前市场处于什么状态
- 创业板权重结构救了它：宁德（20%）vs 光模块双雄（18%），几乎抵消

## 4. 磨底期是建仓期，不是等待期（2026-08-05）

**场景**：一直在等"3天站上MA5确认"，结果确认的时候4-4已经走了一半。

**Why**: "3天站上MA5"是确认信号，不是入场信号。复杂调整浪（4-4/B反）的磨底本来就是浪的一部分——磨底时就应该分批建仓，启动后只是加仓窗口。

**How to apply**:
- 磨底阶段 = 分批建仓窗口（底仓 + 逐步加仓）
- 启动后的回踩 MA5/MA10 = 加仓窗口（不是初次入场）
- 等确认信号 = 等别人都看到了 = 成本已经高了

## 5. 复盘心态（2026-08-05）

**场景**：复盘发现自己错了，框架和市场脱节，有点沮丧。

**应对**：
- 真正有用的复盘不是看数据，是发现自己错了然后改
- 承认"我用旧思维做新行情"比任何技术分析都有价值
- 复盘累了就休息，第二天继续，不要硬撑
- 洗澡是个好办法
